## ✅ Fonctionnalités

### Mobile App (Flutter)
- Interface utilisateur moderne (Material Design)
- Intégration API REST avec `http`
- Gestion de tâches (CRUD)
- Gestion des erreurs et chargements

### Backend (Flutter)
- API REST simple (GET, POST, PUT, DELETE)
- Réponses JSON
- CORS activé pour le mobile
- DB postgres
- pensez a modifier le fichier de comfiguration pour l'adapter aux information de votre base.
